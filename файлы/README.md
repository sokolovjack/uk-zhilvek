# Локальные файлы с ук-жилвек.рф

Скачаны скриптом `scripts/download_files.py`.

## Структура

- `дома/` — папка на каждый дом (договоры, протоколы ОСС, отчёты)
- `компания_и_лицензии/` — устав, лицензия, свидетельство, карточка организации
- `раскрытие_информации/` — тарифы и бухгалтерская отчётность
- `новости/` — вложения из новостей
- `изображения/` — картинки со страниц и новостей
- `manifest.json` — полный список URL → локальный путь

Перескачать / докачать:

```bash
python3 scripts/download_files.py
```

Не скачивается с этой сети: картинка ЭДС с `eds.mosreg.ru` (таймаут).
