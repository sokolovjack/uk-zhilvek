# Сайт УК «ЖилВек» + админка

Публичный сайт и CMS для статей, домов и страниц.

## Быстрый старт

```bash
pip3 install -r requirements.txt
python3 run.py
```

- Сайт: http://127.0.0.1:8080/
- Админка: http://127.0.0.1:8080/admin/

Логин по умолчанию: `admin` / `zhilvek2026`  
Смена через переменные `ADMIN_USER`, `ADMIN_PASSWORD`, `CMS_SECRET`.

## Что умеет админка

- **Статьи** — создавать, править, скрывать и удалять новости
- **Дома** — добавлять адреса, загружать PDF/DOC или вставлять ссылки на документы
- **Страницы** — редактировать тексты разделов (о компании, услуги, контакты и т.д.)
- **Публикация** — пересобрать статический сайт в `docs/`

После «Опубликовать» можно закоммитить `docs/` и выложить на GitHub Pages.

## Команды

```bash
# первичное наполнение из выгрузки ук-жилвек.рф
python3 -m app.seed --force

# только пересборка статики из БД
python3 -m app.publish
```
